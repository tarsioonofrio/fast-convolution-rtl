============
Installation
============


From a clone
------------

Clone the repository and install the package in editable mode:

.. code-block:: console

    $ git clone git@github.com:tarsioonofrio/fast-convolution-rtl.git
    $ cd fast-convolution-rtl
    $ pip install -e .

This installs the ``fast-conv`` command line entry point together with its
dependencies, while keeping the source tree editable.

If you don't have `pip`_ installed, this `Python installation guide`_ can guide
you through the process.

.. _pip: https://pip.pypa.io
.. _Python installation guide: http://docs.python-guide.org/en/latest/starting/installation/
